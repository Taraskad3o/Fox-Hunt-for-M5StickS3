# Fox-Hunt-for-M5StickS3
Fox Hunt for M5StickS3  Active hide-and-seek game for two M5StickS3 devices. One player hides as the Fox, and the other searches as the Hunter.  The game uses radio (ESP-NOW) to track distance like a "hot-or-cold" radar and an infrared beam (IR) on top of the device for direct line-of-sight tag shots.
